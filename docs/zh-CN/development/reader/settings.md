# 阅读设置与管理工具

点击阅读工具栏的齿轮打开设置。订阅管理、多选和维护工具集中在设置页，阅读侧栏只保留文章集合和订阅导航。设置页有独立地址，例如 `i/?view=settings&section=subscriptions`；返回阅读后保留原来的筛选、分页和文章位置。

桌面使用左侧分类导航，窄屏改为分类下拉选择。顶部搜索可以查找分类、工具说明和已加载的设置文字；阅读器字段的搜索结果可以直接定位到输入框。

## 分类与内容

| 分类 | 可以做什么 |
| --- | --- |
| 外观 | 通过带图示与说明的单选块选择主题、日夜配色、布局、阅读风格和密度，查看局部或放大预览；打开语言与时区设置 |
| 阅读与操作 | 设置正文大小、行距、区域宽度和每页数量；调整打开文章、打开原文及内容更新时的已读行为 |
| 订阅与分类 | 按名称、分类和抓取状态筛选订阅，选择后批量修改；添加订阅、管理分类和动态 OPML、管理标签 |
| 过滤与规则 | 设置自动已读和收藏条件、重复标题和最大未读数量；编辑 Rule Engine、测试样本、管理已保存查询和自动标签 |
| 全文与解析 | 为指定订阅打开完整 Feed 设置；管理 Web Extraction 配方、预设与样本解析；打开可视化解析编辑器 |
| 数据与备份 | 导入导出阅读器配置、订阅和文章；下载可用 SQLite 归档、备份扩展配置；管理员可设置自动 SQLite 导出策略 |
| 存储与回收 | 查看数据库大小、文章数、未读数、收藏数和 SQLite 备份占用；设置文章保留规则、正文缓存与 RSS 输出；执行清理和数据库维护 |
| 账号与隐私 | 设置远程图片、扩展目录联网和来源网址白名单；打开邮箱、密码、RSS 令牌和 API 密码的完整账号表单 |
| 扩展与分享 | 启停和配置扩展、查看扩展目录、配置分享服务；管理扩展提供的显示设置 |
| 更新与任务 | 设置默认订阅与动态 OPML 更新间隔、Reader 计数同步；管理员可配置后台队列、暂停或恢复领取任务、查看运行历史 |
| 高级与系统 | 查看统计和日志、阅读器上限；管理员可维护实例、认证、用户和更新 |

## 保存与草稿

外观、排版、阅读偏好与账户设置共用页底的“保存设置”。修改字段后只更新设置页内的局部预览；保存成功后统一应用到整站。规则、解析配方、备份策略和调度配置各有明确的保存操作，这些工具的保存结果不表示其他工具也已保存。

32 个主题使用原生单选按钮组成的视觉选择块，缩略图包含侧栏、文章列表和正文，配有名称和明暗说明。布局、密度和阅读风格同样使用图示选择块，并说明各选项的效果。点击后更新局部预览，需要比较细节时可打开大预览；“跟随系统”可以分别选择日间与夜间主题。返回阅读继续使用已保存的外观；当前页面内重新打开设置，可以继续编辑原草稿。“撤销修改”恢复已保存的外观和账户字段。草稿存在于当前页面，不是持久离线存储，刷新页面前应保存所需更改。

外观设置首屏先显示主题图示块，内嵌大预览放在主题组之后。

保存失败会显示错误并保留草稿与局部预览，阅读主页继续使用已保存的外观。数值类型、单位和范围由服务器提供，错误字段有对应说明。规则和解析配置还会检查读取时的版本：其他页面已经保存过同一配置时，先比较当前服务器配置与本地草稿，再选择采用服务器值或保留草稿继续审阅。

完整管理工具在设置页内打开，保留原有表单、文件上传、提交结果和需要重新认证的流程。点击“返回设置”可以收起工具；存在未保存更改时，原工具页面会保留，并显示“继续编辑”入口。打开另一个工具前会询问是否放弃现有工具草稿。也可以用“独立打开”在新窗口访问完整工具。

## 订阅与批量管理

进入“订阅与分类”，可以组合名称搜索、分类和“全部订阅／抓取失败／已暂停／抓取已启用”筛选。列表显示名称、分类、未读数、抓取状态、更新间隔和非默认显示范围。点击名称进入完整 Feed 设置，点击复选框选择批量目标。

- “选择筛选结果”选择当前匹配的订阅；改变筛选不会丢失已经选中的其他订阅。
- Shift 加点击可以连续选择。复选框获得焦点时，方向键、Home、End 移动焦点，Shift 加方向键扩展选择；Ctrl 或 Command 加 A 选择筛选结果。
- “批量编辑”可修改名称、分类、刷新间隔、启停和显示范围。直接编辑会把改动加入保存范围，恢复原值会取消该项改动；也可以手动排除某项。
- 页面报告实际进度、成功项和未保存项。失败后可以载入未保存项检查，再决定是否重试。

每次批量请求都检查源和分类归属、字段及配置版本，并在事务内提交。跨多次请求的较大操作逐批完成，不构成一个覆盖全部请求的事务。单源 URL、HTTP 认证、代理、抓取类型、全文选择器、去重和保留规则使用完整 Feed 表单，不会被基础批量字段覆盖。

“分类与订阅详情”提供分类新增、排序、动态 OPML、分类过滤和保留策略。“标签管理”可创建、重命名和合并个人标签，并设置自动标签条件。删除订阅、清空文章和分类内批量删除沿用各自的明确操作与确认。

## 过滤、规则与全文解析

“过滤与规则”的账户过滤每行一条条件，可使用 FreshRSS 搜索语法，例如 `intitle:关键词`、`author:作者`、`intext:正文`、`OR`、括号和 `!` 排除。自动已读与自动收藏使用独立字段，清空一类条件不会移除另一类条件。文章接收、源中消失、重复标题和最大未读数量各有独立选项。

Rule Engine 可在设置页中启停和排序规则、添加预设、导入导出配置、编辑高级 JSON，并用样本文章预览动作与匹配说明。需要编辑组合条件、作用域和详细动作时，打开“可视化规则编辑器”。设置可以在扩展未启用时准备；规则真正执行需要到“扩展与分享 → 已安装扩展”启用 Rule Engine。

“全文与解析”支持为指定 Feed 打开 CSS、XPath、JSON 和 HTTP 抓取选项的完整表单。Web Extraction 配方按订阅 ID 保存，`*` 是默认配方；可使用预设、配置导入导出、高级 JSON 和样本测试，详细字段通过“可视化解析编辑器”编辑。应用配方需要启用 Web Extraction。预览只处理输入的 HTML、XML 或 JSON 样本，不访问远程网址，也不改写已存文章。CSS 全文抓取选择器的原有预览仍使用完整 Feed 工具。

## 存储、回收与备份

“存储与回收”的统计来自当前账户数据库和可读取的 SQLite 归档，显示更新时间。“更新统计”重新读取数据，不执行清理或优化。数据库大小与备份占用是不同项目；当前活动的 `db.sqlite` 不计作备份归档。界面没有假定服务器磁盘总容量，也没有据此计算磁盘配额或剩余空间。

自动回收可同时设置保留期限、每源最多和至少保留数量，以及收藏、个人标签和未读文章的保留例外。期限支持年、月、周、天和小时；已有复合周期保留原值，选择“自定义 ISO 8601”可填写 `P1DT6H`（1 天 6 小时）、`PT30M`（30 分钟）等周期，保存时由服务器校验。关闭期限或数量限制表示不按该项回收。规则用于订阅更新时的回收，源和分类可以单独覆盖账户默认值。保存规则不会立即清理旧文章；要执行清理，打开“清理执行与数据库维护”，检查保留策略后使用“立即清理”。数据库优化是另一项操作。

正文缓存数量和 MiB 容量只限制 Reader 当前页面内的正文缓存，不删除服务器文章。RSS 输出数量与时间范围只控制账户 RSS 输出，不改变数据库保留规则。

“数据与备份 → 订阅与文章的导入导出”使用已有 OPML、JSON、ZIP 和 SQLite 归档功能。指定 Feed 的文章导出目前每源最多 50 篇，不能当作该源全部文章的备份；收藏和个人标签文章有单独的导出选项。多文件 ZIP 导出需要服务器启用 PHP ZIP 扩展。

阅读器配置 JSON 包含主题、排版和缓存等偏好，不包含订阅数据库、账号密码或扩展配置。导入与恢复默认值先成为草稿，保存后生效。扩展配置在对应工具中导入导出，敏感字段按扩展声明脱敏。

管理员的“自动 SQLite 备份”可启用导出并设置每位用户保留的份数，至少保留 1 份。它保存 `auto_sqlite_export` 策略；服务器仍需通过定时任务或 CLI 执行 `cli/export-sqlite-auto.php`。界面不会安装 cron，也不会因保存策略立即生成或删除备份；旧文件在成功导出后按份数清理。

## 更新任务与权限边界

默认 Feed 与动态 OPML 更新间隔控制服务器更新的目标周期，实际执行取决于服务器任务。Reader 的自动计数同步只更新当前页面的状态，不代替 Feed 抓取。

管理员在“更新与任务”设置队列启用状态、全局／用户／主机并发、工作进程内存、超时、租约、退避、维护间隔和历史保留。高级参数折叠显示；保存时检查组合约束，例如租约必须大于超时与终止宽限之和。状态区显示待办、运行、重试和到期数量，历史可继续翻页。

暂停队列停止领取新任务，允许已经运行的任务完成；恢复解除暂停。保存配置、暂停和恢复都不会从网页启动工作进程。执行入口、环境要求和运行命令见[后台刷新队列](../backend/scheduler.md)。

账号的“打开文章／打开原文时标为已读”用于阅读主页；更新时的过滤和回收属于账户行为。阅读主页的主题、字号、行距、宽度和密度由阅读偏好控制，原有 Reader Comfort 配置不覆盖这些设置。

普通用户管理自己的订阅、配置和数据。实例、认证、用户、更新、队列、自动备份及可修改的服务器上限限管理员使用。嵌入模式只允许指定的同源设置路由，不增加权限；提交保留原有 CSRF 校验，敏感操作保留重新认证。文章正文使用独立的受限 iframe，与可以运行原有表单脚本的设置工具分开。

## 相关实现与检查

前端代码集中在 `p/scripts/reader/settings/`：分类、完整工具和存储展示在 `page.js`，订阅管理在 `subscriptions.js`，账户字段在 `account.js`，规则、解析与调度在 `configuration.js`，备份策略在 `backup.js`。服务端字段和行为由 `app/Services/Reader/` 下的 `SettingsService`、`StorageService`、`SchedulerSettingsService` 和 `BackupPolicyService` 提供；同源工具路由定义在 `app/Utils/Http/SettingsEmbedPolicy.php`。

设置页、账户字段、工具编辑和嵌入流程有各自的浏览器用例。单元检查覆盖类型、过滤语法、部分字段保存、配置并发、回收与备份边界；浏览器用例覆盖导航、草稿、筛选选择、保存失败、外观保存和窄屏布局。用例名称与运行方式如下，不需要根据测试数量判断功能范围：

```sh
npm run test:frontend
npx playwright test --config tests/browser/config/settings-page.config.mjs
npx playwright test --config tests/browser/config/account-settings.config.mjs
npx playwright test --config tests/browser/config/settings-embed.config.mjs
npx playwright test --config tests/browser/config/default.config.mjs reader/settings/tools.spec.mjs
```

测试服务和账号的要求见各测试配置及[增强说明](../README.md#启动与复现)。测试数据与模拟视口不代替真实设备及长期运行检查。
